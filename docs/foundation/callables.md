# 第 07 讲 · 函数、方法、闭包与表达式

这一讲属于**编程地基**：讲的是「这些东西是什么、为什么需要、彼此什么关系」。`fn` 怎么写、分号怎么加、返回值怎么写这些**语法细节**留到 [第 11 讲](/basics/functions.md)。

<Callout type="idea" title="先记住一句话" text="程序做的事可以概括为：**把数据交给一段逻辑，拿到结果，再交给下一段逻辑**。函数、方法、闭包都是「一段逻辑」的不同打包方式；表达式则是让「拿到结果」这件事贯穿所有代码的规则。" />

## 一、为什么要把逻辑打包

```text
不打包：把同样的 5 行复制 20 遍
        → 改一个地方要改 20 遍，且很容易漏
打包后：给它一个名字，写一次，调用 20 次
        → 改动只发生在一处，逻辑有了边界
```

给一段逻辑起名字、定义它接收什么、交回什么，是编程里最基础的一次抽象。这个「有名字、可复用、有输入输出」的东西，就是**函数**。

<ConceptDiagram type="callable" title="输入值 → 一段命名逻辑 → 输出值，函数是最基本的抽象单元" />

## 二、函数：输入 → 处理 → 输出

```rust
fn add(a: i32, b: i32) -> i32 {
    a + b
}

fn main() {
    let sum = add(2, 3);
    println!("{}", sum);
}
```

| 组成 | 作用 |
| --- | --- |
| 名字 | 之后靠它调用 |
| **参数** | 调用方交进来的数据，相当于「输入接口」 |
| 函数体 | 具体步骤，对外不可见（封装） |
| **返回值** | 交还给调用方的结果 |
| 作用域 | 函数内部创建的变量，函数结束就销毁 |

<Callout type="tip" title="和「栈」的联系" text="每次调用函数，会在栈上压入一个**栈帧**存放参数与局部变量；函数返回时整帧弹出，里面的值随之销毁。这解释了 [第 05 讲](/foundation/memory.md) 的一个经典问题：为什么不能返回局部变量的引用 —— 它所在的栈帧已经没了。" />

## 三、方法：依附于某个值的函数

函数独立存在；**方法**属于某个类型，第一个参数隐含地是「调用它的那个值」。

```rust
struct Rect { w: u32, h: u32 }

impl Rect {
    fn area(&self) -> u32 { self.w * self.h }   // 方法
}

fn double_area(r: &Rect) -> u32 { r.area() * 2 } // 普通函数

fn main() {
    let r = Rect { w: 3, h: 4 };
    println!("{} {}", r.area(), double_area(&r));
}
```

| | 函数 | 方法 |
| --- | --- | --- |
| 归属 | 独立 | 属于某个类型，写在 `impl` 块里 |
| 调用 | `add(1, 2)` | `r.area()` |
| 隐含的 self | 无 | 有（`&self` / `&mut self` / `self`） |
| 适合 | 通用计算、工具逻辑 | 操作该类型自身的数据 |

<Compare title="同一个「面积」的三种写法" :panels='[{"label":"独立函数","code":"fn area(r: &Rect) -&gt; u32 { r.w * r.h }","note":"数据和逻辑分离，显式传参"},{"label":"方法","code":"impl Rect {\n    fn area(&amp;self) -&gt; u32 { self.w * self.h }","note":"逻辑贴在类型上，可读性更好"},{"label":"闭包","code":"let f = |r: &amp;Rect| r.w * r.h;","note":"匿名、可就地定义、能捕获环境"}]' note="三者本质都是「一段逻辑」，区别只在归属、名字与能否捕获环境。" />

## 四、闭包：能记住周围环境的匿名函数

```rust
fn main() {
    let factor = 3;
    let multiply = |x: i32| x * factor;   // 捕获了外面的 factor
    println!("{}", multiply(7));          // 21
}
```

闭包和普通函数最大的差别是**捕获（capture）**：它能「看见」并记住定义时所在作用域里的变量。正因如此，它特别适合做短小的、就地使用的逻辑（排序规则、过滤条件、回调）。

```rust
let nums = vec![1, 2, 3, 4];
let evens: Vec<i32> = nums.into_iter().filter(|n| n % 2 == 0).collect();
```

<Callout type="warn" title="闭包不是「更轻的函数」那么简单" text="因为捕获了外部变量，闭包带着一份环境状态；它能被存起来、传出去，也可能因为捕获方式不同而不能被多次调用。Rust 用 `Fn` / `FnMut` / `FnOnce` 三个 trait 描述这些差异 —— [第 30 讲](/core/closures-iterators.md) 会展开。现在只要知道「能捕获环境」这个特征即可。" />

## 五、表达式：Rust 里几乎一切都有值

这是从 C / Java / JavaScript 转过来的人最容易忽略、却最影响代码风格的一条观念。

| 语言 | `if` 是语句还是表达式 | 常见写法 |
| --- | --- | --- |
| C / Java / JS | 语句（不产生值） | 先声明变量，再在分支里赋值 |
| **Rust** | **表达式（产生值）** | `let x = if cond { 1 } else { 2 };` |

```rust
fn main() {
    let n = 7;
    let label = if n > 5 { "大" } else { "小" };   // if 直接产生值

    let doubled = {
        let t = n * 2;
        t + 1                                      // 代码块最后一行是它的值
    };
    println!("{} {}", label, doubled);
}
```

- **表达式**：计算出一个值（`5 + 3`、`if ... {}`、函数调用、代码块 `{}`）。
- **语句**：做一件事，不产生值（以 `;` 结尾，如 `let x = 5;`）。

<Predict no="07-1" q="下面这段输出什么？" :options='["大 6", "大 ()", "编译错误", "小 6"]' answer="0" output="大 6" explain="if 作为表达式返回 大；代码块里最后一个表达式 t * 3 没有分号，因此代码块的值是 6。" />

```rust
fn main() {
    let a = 5;
    let label = if a > 3 { "大" } else { "小" };
    let b = { let t = 2; t * 3 };
    println!("{} {}", label, b);
}
```

<Callout type="tip" title="为什么这件事值得单开一节" text="因为「一切都有值」让 Rust 代码可以写成一连串值的流动，而不是一堆先声明、再赋值的语句。理解它之后，[第 11 讲](/basics/functions.md) 里「函数最后一行不加分号就是返回值」和「加了分号就返回单元类型」就都是顺理成章的结论，不用死记。" />

## 六、四者对照与术语速查

| 概念 | 一句话 | 有没有名字 | 有没有归属类型 | 能否捕获环境 |
| --- | --- | --- | --- | --- |
| 函数 | 独立的一段命名逻辑 | ✅ | ❌ | ❌ |
| 方法 | 属于某个类型的函数 | ✅ | ✅ | ❌ |
| 闭包 | 能捕获环境的匿名逻辑 | ❌ | ❌ | ✅ |
| 表达式 | 能算出一个值的代码片段 | — | — | — |

| 术语 | 含义 |
| --- | --- |
| 参数 / 实参 | 定义时的占位名 / 调用时真正传进去的值 |
| 返回值 | 交还给调用方的结果 |
| 调用栈 | 函数一层层调用时在栈上形成的帧序列 |
| 作用域 | 名字能被访问的代码范围 |
| 封装 | 只暴露输入输出，藏起内部步骤 |
| 抽象 | 忽略细节，只保留「它能做什么」 |

## 常见坑

| 现象 | 处理 |
| --- | --- |
| 以为 `if` 不能赋值 | 它是表达式，可以直接 `let x = if ...` |
| 函数最后一行加了分号 | 变成语句，返回 `()`；去掉分号 |
| 方法和函数搞混 | 看有没有 `impl` 和 `self` |
| 闭包捕获后外部变量不能用了 | 捕获会移动/借用；[第 16 讲](/core/ownership.md) 会解释 |
| 递归函数无限嵌套 | 需要终止条件，或改用循环 |

## 小结

- 函数 / 方法 / 闭包都是「一段逻辑」的打包方式，区别在名字、归属与能否捕获环境。
- 函数调用会压入栈帧，返回时局部变量随之销毁 —— 这解释了悬空引用为何非法。
- Rust 里**绝大多数代码是表达式**：`if`、代码块、函数调用都有值。
- 「一切都有值」是理解 Rust 返回值、分号坑和链式写法的前提。
- 语法细节见第 11 讲，闭包 trait 见第 30 讲。
