# 第 04 讲 · 程序、数据、值与类型

后面每一讲都会用到「程序、值、类型、变量」这几个词。这一讲先把它们对齐 —— 不写复杂代码，只建立一套能一直用下去的说法。

<Callout type="idea" title="先记住一句话" text="程序 = 数据 + 处理数据的指令；类型规定「这段二进制该怎么解读」；绑定把名字贴到值上。Rust 的特殊之处是：这三件事都在编译期就被检查一遍。" />

## 一、程序怎么跑起来

你写的 `.rs` 是给人看的文本，CPU 只认二进制，中间那一步叫**编译**。

```text
src/main.rs  ──rustc / cargo build──▶  可执行文件  ──运行──▶  屏幕输出
                    ↑ 编译期在这里检查类型、所有权与借用
```

编译型语言的关键特征是：**错误尽量在编译期拦下**，而不是等运行到那一行才崩。这也解释了为什么 Rust 编译器看起来「话很多」—— 它替你提前跑了一遍检查。装环境与第一次编译见 [第 02 讲](/guide/setup.md) · [第 03 讲](/guide/hello.md)。

| 概念 | 一句话 | 例子 |
| --- | --- | --- |
| 源码 | 写给人看的文本 | `fn main() { ... }` |
| 编译器 | 检查 + 翻译的工具 | `rustc`、`cargo build` |
| 可执行文件 | 机器能直接跑的二进制 | `target/debug/hello` |
| 运行时 | 程序真正执行的阶段 | 屏幕打印结果 |

## 二、数据、值与类型

先看这张图：同一份二进制数据，按不同类型去解读，会得出完全不同的含义。

<ConceptDiagram type="value-type" title="值、类型与解读结果" />

**数据**是客观存在的信息；**值**是程序里对数据的一次具体表示，比如 `42`、`3.14`、`"hello"`。**类型**规定了：这个值占多少内存、能对它做哪些操作、二进制位该怎么解读。

```text
值     42          类型  i32        → 4 字节有符号整数，可以做加减乘除
值     true        类型  bool       → 1 字节，可以做逻辑与或非
值     "hello"     类型  &str       → 一段文字的视图
```

同一串二进制位 `0100 0010`，按 `i32` 读是 66，按 `char` 读是字母 B。类型就是「解读方式」的约定 —— 数据本身没有类型，是程序**决定**按什么类型去读它。

Rust 是**静态强类型**语言：每个值的类型在编译期就确定，而且不会偷偷帮你把字符串转成数字。好处是大量错误在编译期就被发现。具体语法见 [第 09 讲](/basics/variables.md)，字符串见 [第 10 讲](/basics/strings.md)。

## 三、变量、绑定与可变性

很多语言说「给变量赋值」，Rust 更准确的说法是「**把值绑定到名字上**」：

```rust
let x = 5;        // 把 5 绑定到名字 x
let mut y = 5;    // mut 表示这个绑定允许被换一个值
y = 6;            // 可以
// x = 6;        // 编译错误：x 不可变
```

<Term word="绑定" text="把一个名字和一个值关联起来。Rust 用 let 创建绑定，默认不可变。" />

**默认不可变**是 Rust 一个非常刻意的设计：如果一个值从头到尾不会变，读代码的人就不用在脑子里追踪它被谁改过。并发编程时，这还直接消除了「两个线程同时写」的可能。

注意 `mut` 改的是**绑定能不能重新指向别的值**，不是值本身能不能被修改 —— 这两者的区别会在 [第 19 讲](/core/mutable-borrow.md) 变清楚。

## 四、常见类型速览

| 类别 | 类型 | 例子 |
| --- | --- | --- |
| 有符号整数 | `i8` `i16` `i32` `i64` `i128` `isize` | `-10`、`42` |
| 无符号整数 | `u8` `u16` `u32` `u64` `u128` `usize` | `0`、`255` |
| 浮点 | `f32` `f64` | `3.14` |
| 布尔 | `bool` | `true` / `false` |
| 字符 | `char` | `'中'`（4 字节，Unicode 标量值） |
| 文本 | `&str` / `String` | `"hello"`（`&str` 视图） |

`usize` / `isize` 的宽度跟机器字长一致，通常用来做索引和长度。Rust 还能从上下文**推导**类型，不必处处手写；完整语法见 [第 09 讲](/basics/variables.md)。

<Callout type="warn" title="整数不会偷偷转换" text="`let a: i32 = 5; let b: i64 = a;` 会编译失败。Rust 不做隐式数值转换，必须写 `a as i64` 或 `.into()` —— 这是为了防止悄悄溢出或丢精度。" />

## 五、语句与表达式

顺带建立一个会反复用到的观念：**Rust 里绝大多数代码都是表达式，都有值**。

```rust
fn main() {
    let a = 5;                                  // 语句：以分号结尾，不产生值
    let label = if a > 3 { "大" } else { "小" }; // if 是表达式
    let b = { let t = 2; t * 3 };                // 代码块最后一行是它的值
    println!("{} {}", label, b);                 // 大 6
}
```

<Callout type="warn" title="最容易踩的一处" text="函数体最后一行如果加了分号，它就从「返回值」变成「语句」，函数返回空元组 ()，于是报类型错误。记住：要返回就不写分号。" />

<Predict no="04-1" q="这段程序输出什么？" :options='["大 6", "大 ()", "编译错误", "小 6"]' answer="0" output="大 6" explain="if 作为表达式返回 &quot;大&quot;；代码块里最后一个表达式 t * 3 没有分号，因此代码块的值是 6。" />

## 常见坑

| 现象 | 处理 |
| --- | --- |
| `expected i64, found i32` | 整数不隐式转换，写 `as i64` 或改字面量类型 |
| 改了 `let x` 的值却编译失败 | 默认不可变，需要 `let mut x` |
| 函数返回报 `expected ..., found ()` | 最后一行多写了分号，去掉它 |
| 以为类型只影响「能存什么」 | 类型还决定能做什么操作、二进制怎么解读 |

## 小结

- **程序 = 数据 + 指令**，编译期把类型、所有权、借用错误提前拦下。
- **类型**是解读二进制的约定；Rust 静态强类型、不做隐式转换。
- `let` 创建**绑定**，默认不可变；`mut` 允许重新赋值。
- **绝大多数代码是表达式**，`if`、代码块、函数最后一行都能产生值。
- 地址、指针、引用见[第 06 讲](/foundation/pointers.md)，它们是同一块内存的另一面。
