# 阶段一 · 编程地基

很多 Rust 教程让人觉得难，不是因为 Rust 本身，而是因为它默认你已经知道「栈」「堆」「指针」「引用」「值语义」这些词。本阶段专门把这些补上。

## 为什么值得花五讲补地基

Rust 最核心的机制叫**所有权**，它解决的问题是：**一块内存，谁负责释放？**

其他语言用两种办法绕开了这个问题：

- **垃圾回收（GC）**：Java / JavaScript / Python / Go 由运行时统一扫描、替你回收。你不用管，但程序会时不时停下来做这件事。
- **手动管理**：C / C++ 由你自己 `malloc`/`free`。性能完全可控，但忘了释放就泄漏，释放早了就崩溃。

Rust 选了第三条路：**让编译器在编译期就搞清楚每个值的生命周期，自动插入释放代码**。你既不用写 `free`，也没有 GC 停顿。代价是：编译器必须知道值住在哪、谁拥有它、什么时候不再被使用 —— 于是这些概念就从「底层细节」变成了「日常语法」。

## 学习建议

这一阶段以概念为主，代码不多，但**请不要跳过**。建议配合图解与 [第 07 讲](/foundation/callables.md) 的最小示例，试着用自己的话解释下面三个问题；能说清楚，L3 的所有权就会顺畅很多：

1. 为什么整数赋值之后两个变量都能用，字符串赋值之后原变量就不能用了？
2. 指针和引用有什么区别？
3. 「函数返回后，局部变量去哪了？」
