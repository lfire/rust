# 第 08 讲 · 为什么值得学 Rust

学一门新语言之前，先搞清楚它到底在解决什么问题，会让你在遇到挫折时更有耐心 —— 尤其是 Rust，它的前期学习曲线确实比 Python 陡。

## 一句话概括

> **Rust 让你写出接近 C/C++ 性能的程序，同时由编译器保证不会出现内存错误和数据竞争。**

拆成三个关键词：

**内存安全。** 空指针解引用、悬空指针、重复释放、数组越界、缓冲区溢出 —— 这些占了系统软件安全漏洞的很大一部分。Rust 通过所有权和借用检查，让这类代码**根本编译不过**，而不是靠测试碰运气。

**零成本抽象。** 迭代器、泛型、trait 这些好用的高层写法，编译后和手写循环几乎一样快。你不必在「代码好读」和「跑得快」之间二选一。

**无畏并发。** 「两个线程同时改同一块数据」这类 bug 极难复现。Rust 把线程安全写进类型系统（`Send` / `Sync`），编译期就能拦住。

## 和其他语言的取舍

| 语言 | 内存管理 | 典型优势 | 典型代价 |
| --- | --- | --- | --- |
| Python / JS | GC | 上手极快、生态庞大 | 运行时开销、类型错误留到运行时 |
| Java / Go | GC | 工程化成熟、并发模型简单 | GC 停顿、对内存布局控制弱 |
| C / C++ | 手动 | 极致性能与可控 | 内存安全靠人，漏洞成本高 |
| **Rust** | **编译期所有权** | **安全 + 性能 + 并发** | **学习曲线陡、编译期要求严格** |

<Callout type="idea" title="Rust 不是要取代谁" text="写个一次性脚本、做个数据探索，Python 依然更合适；写业务后台，Java / Go 的团队成本更低。Rust 的甜区是：需要长期运行、对性能和资源敏感、且出错代价高的系统 —— 浏览器引擎、数据库、网络服务、操作系统组件、CLI 工具链、嵌入式、WASM。" />

## 生态里已经有哪些「轮子」

进入 L5 之前先有个印象：Rust 的库叫 **crate**，统一发布在 crates.io。常用的几类：

| 类别 | 代表 crate | 教程里会用在哪 |
| --- | --- | --- |
| 序列化 | `serde` / `serde_json` | 待办清单、KV 协议 |
| 命令行 | `clap` | mini-grep、CLI 工具 |
| HTTP | `reqwest`（客户端）、`axum`（服务端） | 网页抓取、图片服务器 |
| 异步运行时 | `tokio` | KV Server 异步化 |
| 错误处理 | `thiserror` / `anyhow` | 生产化章节 |
| 数据库 | `sqlx` | 数据工具章节 |

这些都会在实战里逐个用到，现在不用记。

## 关于「难」

Rust 的难点高度集中在**一处**：所有权与借用。跨过它之后，泛型、trait、并发、异步都会变得顺理成章，因为它们是同一套思路的延伸。

所以本教程把 L3 拆成 15 讲慢慢磨，还配了可以逐语句演示栈与堆的交互实验台。你不需要「天赋异禀」，只需要按节奏走。

## 小结

- Rust 的核心价值：**内存安全 + 零成本抽象 + 无畏并发**，全部由编译期检查保证。
- 代价是陡峭的前期学习曲线，难点集中在所有权。
- 它的甜区是长期运行、性能敏感、出错代价高的系统软件。
