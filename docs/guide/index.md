# 如何使用这套教程

欢迎。如果你从没写过 Rust，甚至不太确定「编译」和「运行」有什么区别，那你来对地方了。

<Callout type="tip" title="第一次来？先读第 01 讲" text="[第 01 讲 · 开篇：基础概念串讲](/guide/opening.md) 用一讲把程序、类型、内存、函数、所有权、并发与工程串成一张地图，是整套教程的真正起点。本页讲的是工具用法与学习方法。" />

这套教程的编写原则只有一句话：**不跳步**。原始教学材料（仓库里的 `rust-coding/`）面向有经验的开发者，开篇第一课就让你用 `reqwest` 写 HTTP 抓取工具 —— 对零基础的人来说，那相当于还没学会走路就先跑马拉松。所以我们保留它的知识主线，但重新铺了一条更缓的坡道。

## 你会经历六个阶段

<PathMap />

| 阶段 | 解决什么问题 | 学完你能做什么 |
| --- | --- | --- |
| L0 导学 | 环境、第一行代码、学习方法 | 能把一个 Rust 程序跑起来 |
| L1 编程地基 | 程序 / 值 / 类型 / 栈与堆 | 看得懂「内存里发生了什么」的图 |
| L2 语法入门 | 变量、函数、控制流、Cargo | 写出几十行的小工具 |
| L3 核心机制 | 所有权、借用、trait、错误处理 | 能读懂并修复编译器的报错 |
| L4 并发异步 | 线程、锁、channel、Future | 写出并发安全的程序 |
| L5 工程实战 | 九类场景（含 Rust × 前端与桌面）、完整项目演进 | 独立搭出一个可维护的服务 |

阶段之间是**依赖**关系，不是并列关系：L2 的 `String` 会在 L3 变成理解所有权的主角；L3 的 trait 会在 L5 变成整个 KV 服务的骨架；L4 的异步会在 KV 服务第 3 步真正落地。跳阶段不会省时间，只会把困惑攒到一起。

## 每一节都长同一个样子

为了让你不用重新适应版式，每节固定由五块组成：

1. **顶部信息条**：难度、预计时间、本节目标、前置知识，右侧可以「标记学完」打卡。
2. **正文**：先给生活化的直觉，再给术语和代码，最后解释「为什么这样设计」。
3. **交互练习**：随堂检测、结果预测、代码填空、分步实现 —— 答错会给解释，而不是只判对错。
4. **图解与实验台**：抽象概念尽量画出来；所有权部分可以逐语句看栈和堆怎么变化。
5. **小结 + 清单**：一屏内回顾要点，勾掉清单再进入下一节。

<Callout type="tip" title="所有 Rust 代码块都能一键运行" text="每个 Rust 代码块的左上角有一个「在线运行」按钮，会把代码送到官方 Rust Playground。没装环境也能先试；装了环境以后，更推荐你在本地亲手敲一遍。" />

## 三种最有效的学习方式

**先猜，再看答案。** 遇到「结果预测」卡片时，别急着点「揭晓答案」。猜错的那一下，恰恰是理解真正发生的时候。

**一定亲手敲代码。** 读代码和写代码是两种能力。Rust 的编译器报错出了名地详细，把它当成一对一的辅导老师，而不是拦路虎。看到 `error[E0382]` 别慌，L3 会专门教你怎么读它。

**用对比建立锚点。** 教程里会频繁出现「Python / JavaScript 怎么写 → Rust 怎么写」的对照。你已有的知识不是负担，是最好的参照物。
